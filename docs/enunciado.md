# Examen Parcial #1
## Desarrollo de Software 8

Se desea implementar un sistema de parqueo inteligente para monitorear la ocupación de los
estacionamientos en un centro comercial. El equipo debe simular en Python cómo funcionaría el
sistema. Se deben generar datos simulados y procesarlos con Python.
1. Manejar datos como espacios ocupados, tarifa de estacionamiento, placa de autos, etc.
2. Definir constantes (Ejemplo Capacidad máxima), Variables (ejemplo: autos entrando/saliendo)
3. Calcular porcentaje de ocupación.
4. Validaciones para saber si el parqueo está “lleno”, “medio ocupado” o “disponible”.
5. El usuario (o aleatoriamente) podrá indicar cuántos autos entran o salen en un ciclo de simulación.
6. Mostrar en pantalla cuántos espacios quedan libres.
7. Manejar errores cuando el usuario ingrese valores inválidos
8. Guardar las placas de los autos estacionados en una lista.
9. Permitir mostrar todos los autos que están dentro en un momento dado.
10. Guardar cada evento de estacionamiento como una tupla (placa, hora de entrada/salida, tarifa)
11. Manejar un diccionario donde la clave sea la placa del auto, y muestre el historial de eventos del auto.
12. Incluir un README.md con instrucciones para ejecutar el programa, los nombres de los que trabajaron y el número de grupo.
